Your 8-Task Roadmap to Building the TechBridge Platform

TechBridge provides a structured, 30-day practical internship where you progressively develop real-world web development skills by shipping hands-on projects. Start with foundational HTML5 and CSS3 layouts on Day 1, layer in JavaScript interactivity, and assemble a complete, full-featured internship platform by Day 26.

Complete 8-Task Internship Roadmap

Click “Deliverables & What You Will Build” on any task card to inspect technical specs and expected outcomes.

  • Day 1 Kickoff · Step 1 of 8
    Task 01 Upcoming
    Beginner

    Build the TechBridge Homepage

    Create the first version of the TechBridge website using HTML and CSS, establishing core brand identity and landing page layouts.

    Deliverables & What You Will Build Inspect specs
    Expected Build Requirements
    • Semantic HTML5 document layout with header, hero section, mission overview, and footer.
    • Consistent TechBridge color palette, typography scale, and reusable button components.
    • Responsive mobile-first layout using CSS Flexbox and clean spacing tokens.
    Core Technologies
    HTML5 Semantics CSS3 Variables Responsive Design Flexbox
    Output file: index.html
  • Day 4 +3 Days · Step 2 of 8
    Task 02 Upcoming
    Beginner

    Build the TechBridge Programs Experience

    Create a dedicated Programs experience presenting TechBridge's available learning tracks, curriculum details, and enrollment pathways.

    Deliverables & What You Will Build Inspect specs
    Expected Build Requirements
    • Multi-column CSS Grid catalog showcasing TechBridge learning tracks and durations.
    • Clear program cards displaying outcomes, prerequisites, and track features.
    • Seamless cross-page navigation linking index.html and programs.html.
    Core Technologies
    CSS Grid Card UI Systems Multi-Page Nav
    Output file: programs.html
  • Day 8 +4 Days · Step 3 of 8
    Task 03 Upcoming
    Beginner → Intermediate

    Build the Internship Tasks Experience

    Create an interface that presents the TechBridge internship tasks and helps users understand the entire 30-day internship journey and progression.

    Deliverables & What You Will Build Collapse specs
    Expected Build Requirements
    • Clear visual timeline presenting all 8 official tasks from Day 1 to Day 26.
    • Visual communication of difficulty tiers from Beginner to Advanced.
    • Pure HTML5 & CSS3 expandable drawers for task deliverables without JS dependency.
    Core Technologies
    Timeline Architecture HTML5 <details> CSS Transitions UX Hierarchy
    Output file: tasks.html
  • Day 11 +3 Days · Step 4 of 8
    Task 04 Upcoming
    Beginner → Intermediate

    Build an Interactive Task Tracker

    Use JavaScript to make the internship task experience interactive, allowing interns to filter tasks, toggle completion states, and track progress.

    Deliverables & What You Will Build Inspect specs
    Expected Build Requirements
    • Interactive status toggles to mark tasks as Completed, In Progress, or Pending.
    • Dynamic progress bar calculating completed tasks out of 8 in real time.
    • Client-side state persistence using browser localStorage.
    Core Technologies
    Vanilla JavaScript DOM Manipulation Event Listeners localStorage
    Output Upgrade: tasks.html + JS
  • Day 15 +4 Days · Step 5 of 8
    Task 05 Upcoming
    Intermediate

    Build the Intern Registration Experience

    Create a professional registration and onboarding interface for TechBridge interns with input validation and profile configuration.

    Deliverables & What You Will Build Inspect specs
    Expected Build Requirements
    • Accessible multi-section onboarding form with clear labels and inline validation feedback.
    • Track preference selector, experience level assessment, and portfolio/GitHub URL inputs.
    • Confirmation summary screen generating a unique Intern ID upon valid submission.
    Core Technologies
    HTML5 Forms Client Validation Accessibility (ARIA) Onboarding UX
    Output file: register.html
  • Day 19 +4 Days · Step 6 of 8
    Task 06 Upcoming
    Intermediate

    Build the Task Submission System

    Create an interface through which interns can prepare, verify, and submit their completed task work including live demo URLs and reflection notes.

    Deliverables & What You Will Build Inspect specs
    Expected Build Requirements
    • Task selector dropdown paired with a pre-submission quality assurance checklist.
    • Structured fields for GitHub repository URL, hosted demo link, and reflection notes.
    • Submission history log displaying timestamps and review status badges.
    Core Technologies
    Form Workflows URL Validation JSON State UI Feedback
    Output file: submit.html
  • Day 22 +3 Days · Step 7 of 8
    Task 07 Upcoming
    Intermediate → Advanced

    Build the Intern Dashboard

    Create a centralized dashboard where an intern can view their profile, overall 30-day progress metrics, active tasks, and recent submissions.

    Deliverables & What You Will Build Inspect specs
    Expected Build Requirements
    • Sidebar + main workspace grid layout with intern profile card and cohort rank.
    • Visual progress rings/bars summarizing completed tasks and submission status.
    • Quick-action feed connecting directly to active tasks and submission history.
    Core Technologies
    Dashboard Layout Data Visualization Cross-Page State Responsive Grid
    Output file: dashboard.html
  • Day 26 Capstone Milestone
    Task 08 Capstone
    Intermediate → Advanced

    Build the Complete TechBridge Internship Platform

    Combine the different components created during the internship into a complete, cohesive TechBridge platform delivering seamless end-to-end navigation.

    Deliverables & What You Will Build Inspect specs
    Expected Build Requirements
    • Full integration of Homepage, Programs, Tasks Roadmap, Registration, Submissions, and Dashboard.
    • Unified CSS architecture, shared navigation/footer, and synchronized intern state across views.
    • Production-ready responsiveness, accessibility audit, and portfolio-grade polish.
    Core Technologies
    System Architecture Design Tokens Full-App Integration QA & Polish
    Output: Complete TechBridge Platform
